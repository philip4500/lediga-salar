Widget för iPhone
  1. Installera gratisappen Scriptable.
  2. Tryck på knappen nedan, öppna Scriptable, tryck + och klistra in.
  3. Döp skriptet till Datorsalar.
  4. Håll in hemskärmen → + → Scriptable → välj medium eller stor → håll in widgeten → Redigera → Script: Datorsalar.
Lägg till hela sidan som app: Dela → Lägg till på hemskärmen.
